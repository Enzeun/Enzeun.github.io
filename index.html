About

기계공학을 전공하고 게임 스타트업에서 3년 8개월간 Unreal 기반 VR·메타버스 프로젝트를 개발했습니다. Steam 출시, 대사관 외주, 체험관 납품을 거치며, 만드는 일보다 끝까지 완성해 내보내는 일이 어렵다는 것을 배웠습니다. 퇴사 후 개발 현장을 잠시 떠났지만, 다시 돌아오기 위해 Unity와 C#을 쌓아 왔습니다.

코드를 외우기보다 원리를 이해하려 하고, 항상 "왜?"를 먼저 묻습니다. 서드파티 프레임워크는 직접 수정하지 않고 이벤트 흐름을 분석해 확장했으며, 임시 해결은 임시라고 적고 개선 계획까지 남깁니다. 코드 리뷰, 예외 케이스 점검, 품질 확인에 AI를 적극 활용하고, 원리를 이해한 뒤 반영합니다.

Unity 클라이언트 개발자로서 멀티플레이와 시스템 설계 역량을 넓히고, 팀이 믿고 맡길 수 있는 개발자로 성장하겠습니다.
